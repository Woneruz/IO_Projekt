# IO_Projekt

Projekt zespołowy z Inżynierii Oprogramowania (AGH, 2026/27): system automatycznej anonimizacji nagrań wideo i audio dla ReportersWatch Sp. z o.o.

Zespół: Joanna Żupnik, Marcel Kuźma, Arkadiusz Baran

## Dokumentacja

- [Dokumentacja inżynierii wymagań](docs/DIW.md)

## Struktura repozytorium

- `docs/` – dokumentacja inżynierii wymagań i rysunki
- `backend/` – serwer (Python 3.12, FastAPI); podfoldery `app/` odpowiadają komponentom z rozdziału 10 dokumentacji
- `frontend/` – interfejs webowy (TypeScript, React)
- `.env.example` – wzór ustawień (prawdziwy plik `.env` nie trafia do repozytorium)
