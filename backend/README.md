| Folder | Komponent |
|---|---|
| `app/access/` | K1. Dostęp i administracja |
| `app/storage/` | K2. Przyjmowanie i przechowywanie |
| `app/anonymizer/` | K3. Silnik anonimizacji |
| `app/live/` | K4. Transmisja na żywo |
| `app/stats/` | Statystyki |
