# K2. Przyjmowanie i przechowywanie

Walidacja plików wejściowych, szyfrowanie AES-256, zapis oryginałów i wyników, usuwanie danych po upływie retencji, odtworzenie oryginału dla osoby uprawnionej. Tylko ten moduł ma dostęp do magazynu i kluczy szyfrujących.

Wymagania: WF-04, WF-05, WF-19, WF-20, WF-21, NF-07, NF-09.
