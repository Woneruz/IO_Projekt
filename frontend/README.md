# K5. Interfejs webowy

TypeScript, React. Wgrywanie plików, wybór kategorii FACE / TXT / VOICE, profil reportera, podgląd i korekta wyniku, statystyki. Interfejs po polsku, zgodny z WCAG 2.1 AA.

Wymagania: WF-04, WF-06, WF-11, WF-15, WF-16, WF-22, WF-23, WF-24, NF-10, NF-12.
